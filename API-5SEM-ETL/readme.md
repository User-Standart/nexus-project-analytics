# API-5SEM-ETL

ETL pipeline for the Nexus Data Warehouse, built with Python and Polars.

---

# How to run the project

## Prerequisites

- Python 3.11+
- pip

## Linux

1. Install Python and pip
```
sudo apt update
```
```
sudo apt install python3 python3-pip
```

## Windows

1. Download and install Python 3.11+ from the official website
```
https://www.python.org/downloads
```
During installation, check the **"Add Python to PATH"** option.

## Next steps (for both Linux and Windows)

1. Clone the repository and open the ETL folder
```
git clone https://github.com/User-Standart/nexus-project-analytics.git
```
```
cd nexus-project-analytics/API-5SEM-ETL
```

2. Install the dependencies
```
pip install polars
```

3. Add the source CSVs to the `data/` folder

   The following files are expected:
   - `projetos.csv`
   - `programas.csv`
   - `tarefas_projeto.csv`
   - `tempo_tarefas.csv`
   - `materiais.csv`
   - `fornecedores.csv`
   - `solicitacoes_compra.csv`
   - `pedidos_compra.csv`
   - `compras_projeto.csv`
   - `empenho_materiais.csv`
   - `estoque_materiais_projeto.csv`

4. Run the pipeline
```
python etl/main.py
```

The output files will be saved in the `dw/` folder.

# Project structure

The project follows a **modular** folder structure, where files are organized by their responsibility within the pipeline.

```
API-5SEM-ETL/
│
├── docs/                        # Documentation and modeling artifacts
│   ├── csv_analysis.md          # Analysis of the source CSVs (structure, integrity, mapping)
│   ├── modelo_relacional.png    # OLTP relational model
│   └── modelo_estrela.png       # OLAP star schema
│
├── data/                        # Source CSVs (not versioned)
│   └── .gitkeep
│
├── etl/                         # ETL pipeline
│   ├── main.py                  # Entry point — orchestrates the full pipeline
│   ├── extract.py               # Reads the source CSVs
│   ├── load.py                  # Writes the tables to /dw
│   └── transform/
│       ├── __init__.py          # Exposes all transformation functions
│       ├── dimensoes.py         # build_dim_* functions for the 7 dimensions
│       └── fatos.py             # build_fato_* functions for the 3 fact tables
│
├── dw/                          # Generated by the pipeline (not versioned)
│
├── .gitignore
└── README.md
```

### What each file does

- **`main.py`** — the only file you run. Calls extract, transform and load in the right order.
- **`extract.py`** — reads the CSVs from the `data/` folder and returns the raw DataFrames.
- **`load.py`** — saves the processed DataFrames as CSVs in the `dw/` folder.
- **`transform/dimensoes.py`** — builds the 7 dimensions (time, project, supplier, etc.).
- **`transform/fatos.py`** — builds the 3 fact tables with joins on the dimensions and handling of null surrogate keys.
- **`transform/__init__.py`** — makes `transform` a Python package, enabling `from transform import ...` in `main.py`.
